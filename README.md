## Model Architectures

The core of this reproducibility study centers on the **Bilinear MLP**, an architecture designed to facilitate mechanistic interpretability directly from model weights. Unlike standard MLPs that use fixed non-linearities (e.g., ReLU or GeLU), Bilinear MLPs utilize a gated quadratic interaction.

### 1. The Bilinear MLP Layer
The fundamental transformation in these models replaces the standard activation function with an element-wise product of two linear projections. For an input vector $\mathbf{x}$, the output $\mathbf{y}$ is defined as:

$$\mathbf{y} = (W_1 \mathbf{x} \odot W_2 \mathbf{x})W_3$$

Where:
* **$W_1, W_2 \in \mathbb{R}^{d_{hidden} \times d_{in}}$**: These matrices project the input into a latent space where the bilinear interaction occurs.
* **$W_3 \in \mathbb{R}^{d_{out} \times d_{hidden}}$**: This matrix projects the gated features back to the output dimension.
* **$\odot$**: Denotes the Hadamard (element-wise) product.

### 2. Implementation Variants
We evaluate the following architecture:

* **Bilinear Image Classifiers:** Shallow networks used for Claims 1–4. 
    * **Configuration:** Typically 2–3 layers deep with a consistent hidden dimension of **1024 units** to ensure sufficient capacity for eigenvector decomposition.

### 3. Interpretability Tools
* **Sparse Autoencoders (SAEs):** To validate the interpretability of the weights, we train SAEs on the activations of the bilinear layer. This allows us to compare learned features (SAE encoder weights) against the leading eigenvectors of the $W$ matrices.
* **Eigenvalue Analysis:** We perform a low-rank approximation of the weight matrices to identify "interpretable directions" that correspond to specific semantic or visual features.
